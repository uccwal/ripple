# Handoff: RIPPLE UI (S1–S6)

## 개요
RIPPLE — 정책 파급 스트레스 테스트 Agent의 프론트엔드 화면 설계. 정책 이벤트 → Agent 7단계 실행 → 파급 경로·시나리오·손익·보고서 확인 흐름 전체와, 모든 수치에서 열리는 계산 근거 패널(S5)을 포함한다.
대상 저장소: `ripple/frontend` (Vue 3 + Vite + TS, Pinia, Vue Router, Tailwind, ECharts, Vue Flow — `CLAUDE.md` 2장·10장 기준).

## 디자인 파일에 대해
`RIPPLE Prototype.dc.html`은 **HTML로 만든 디자인 레퍼런스**다. 의도한 모양과 동작을 보여주는 프로토타입이며 그대로 옮겨 쓸 코드가 아니다. 이 문서와 프로토타입을 기준으로 **Vue 3 + Tailwind 환경에서 컴포넌트로 다시 구현**한다. (브라우저에서 열려면 같은 폴더의 `support.js`가 필요하다.)
프로토타입의 데이터는 전부 가상이며, 실제 구현에서는 `CLAUDE.md` 9장 API(`/api/runs/{id}`, SSE 등)에서 받는다.

## 충실도
**High-fidelity.** 색상·타이포·간격·상태 표현은 최종안. 아래 토큰과 수치를 그대로 쓴다. 단, 차트(막대·도넛)는 ECharts로, 파급 경로 그래프는 Vue Flow로 구현하되 시각 스펙(선 굵기·색·점선)을 맞춘다.

## 전역 규칙
- 데스크톱 전용. 기준 폭 1440px, 최소 1280px (`min-width:1280px`). 모바일 미대응.
- 폰트: Pretendard Variable (`https://cdn.jsdelivr.net/gh/orioncactus/pretendard@v1.3.9/dist/web/variable/pretendardvariable-dynamic-subset.min.css`). 기본 14px / line-height 1.5 / letter-spacing −0.005em. 한글 `word-break: keep-all`.
- 모든 수치 `font-variant-numeric: tabular-nums`. 음수 부호는 유니코드 마이너스 `−`(U+2212), 양수는 `+`.
- **손익 색상: 국내식.** 이익(>0) `#D23F31`, 손실(<0) `#1E5BD8`, 0·없음 `#4A5363`/`#7A8394`.
- **클릭 가능한 수치**: `text-decoration: underline dotted; text-decoration-thickness:1px; text-underline-offset: 3px(본문)/4px(16px)/5px(30px)`. 클릭 시 S5 패널. 컴포넌트는 `calcId` + `key`를 props로 받는다 (`CLAUDE.md` 10장).
- 배지·칩·탭·버튼·단계 이름은 `white-space:nowrap; flex:none` (줄바꿈 금지).
- 페이지 배경 `#F5F6F8`, 카드 = 흰 배경 + `1px solid #E3E6EB` + radius 8px, 그림자 없음.

## 인터랙션 · 상태
- **SSE → 타임라인**: `step_started` → 실행 중, `step_finished` → 완료(+elapsed_ms, summary), `step_retry` → 반려·재시도(Validator) + 대상 Agent 실행 중(시도 +1), 이후 단계들은 대기로 되돌림, `run_finished` → 완료/partial/failed. 프로토타입 데모 시퀀스: EA 0.9s → IM 1.7s → SB → RF → RE → VA 반려 → IM 재추론(2차) → SB → RF → RE → VA 통과 → RW. 완료 시 토스트 "분석 완료 · 검증 통과".
- **토스트**: 하단 중앙 28px, `#16264A` 배경, 흰 13px/600, radius 6, 3.2초 후 사라짐.
- 상단 바 실행 중 pill은 실행 중에만 노출, 다른 화면에서도 S3로 복귀 가능.
- 애니메이션은 스피너 회전(0.8s linear infinite) 하나뿐. 패널/탭 전환은 즉시(추가 시 150–200ms ease-out 권장).

**권장 Pinia 스토어**
- `runStore`: `run`(RunState), `steps[]`({agent, status: wait|running|done|retry|failed|skip, attempt, elapsedMs, note, input/output 요약, model, tokens}), `isStreaming`, `activeTab`, `selectedNodeId`, `draftShocks`, `isDirty`(draft ≠ applied), `startedAt`.
- `uiStore`: `calcPanel`({calcId, key} | null), `toast`.
- `eventStore`: `filters`({country, type, period}), `events[]`.
- `portfolioStore`: `selectedId`, `holdings[]`.
