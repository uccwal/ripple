## 주제

**투자 및 금융 업무 혁신을 위한 AI Agent 개발.** 단순 질의응답형 챗봇이 아니라 목적을 이해하고 정보를 탐색·분석하며 도구를 활용해 결과물을 만드는 Agent의 실제 적용 가능성을 검증한다.

## 규칙 요약 (준수 체크리스트)

- [ ] 외부 데이터: 법적으로 접근 가능하고 사용 제한이 없는 데이터만. 저작권·개인정보보호법 준수.
- [ ] AI 모델·API: 사용 조건과 라이선스 준수, 비용은 참가자 부담.
- [ ] 사용한 모든 외부 자원을 기록하고 제출물에 출처 명시 → `data/SOURCES.md`, `docs/THIRD_PARTY.md`
- [ ] **데이터 출처, 수집일, 라이선스, 전처리 방법을 제출물에 반드시 기재** → `data/SOURCES.md` + 앱의 계산 근거 패널
- [ ] 독창적 작업일 것. 기존 공개·상용 결과물 그대로 제출 금지.
- [ ] 운영진이 실행 환경·모델·데이터·API 이용 내역·저장소 이력을 요청할 수 있음 → 커밋 이력 유지, `agent_step` 로그 보존
- [ ] 마감 후 수정 불가. 팀장만 제출 가능.
